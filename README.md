# 📚 Attendance Tracker

A simple and responsive attendance tracking web app built with **HTML, Tailwind CSS, and Vanilla JavaScript**. Easily manage your class routine, mark attendance, and monitor your overall attendance percentage.

## ✨ Features

- 📅 Weekly class routine management
- ✅ Mark Present, Absent, or Cancelled
- 📊 Subject-wise attendance statistics
- 📈 Overall attendance progress
- 📖 Attendance history with date filter
- ⚠️ Low attendance alerts
- 🔥 Attendance streak tracking
- 🎯 Attendance predictor
- 📱 Fully responsive (Desktop & Mobile)
- 💾 Offline support using Local Storage

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Local Storage
- Lucide Icons
